# Site Mirror Proxy

Прокси-сервер для зеркалирования сайтов с автоматической конвертацией абсолютных ссылок в относительные.

## Установка

```bash
npm install
```

## Настройка

Открой `server.js` и измени переменную `TARGET_SITE` на нужный сайт:

```javascript
const TARGET_SITE = 'https://example.com';
```

Также можешь изменить порт (по умолчанию 3000):

```javascript
const PORT = 3000;
```

## Запуск

Для разработки (автоперезагрузка при изменениях):
```bash
npm run dev
```

Для разработки с автосинхронизацией в Git:
```bash
npm run dev:sync
```

Для продакшена:
```bash
npm start
```

Для запуска только Git синхронизации:
```bash
npm run sync
```

Сервер запустится на `http://localhost:3000`

## Git синхронизация

Автоматическая синхронизация кеша в Git репозиторий каждые 5 минут.

Настройка через переменные окружения:
```bash
GIT_REMOTE=origin        # Имя remote (по умолчанию origin)
GIT_BRANCH=main          # Ветка (по умолчанию main)
SYNC_INTERVAL=300000     # Интервал в мс (по умолчанию 5 минут)
```

Перед использованием:
1. Инициализируй git репозиторий: `git init`
2. Добавь remote: `git remote add origin <url>`
3. Сделай первый коммит: `git add . && git commit -m "Initial commit"`
4. Запусти с синхронизацией: `npm run dev:sync`

## Как работает

1. Принимает все запросы на localhost:3000
2. Проксирует их на оригинальный сайт
3. Для HTML-страниц парсит контент и заменяет абсолютные URL на относительные
4. Обрабатывает: ссылки, изображения, скрипты, стили
5. Остальные ресурсы (CSS, JS, картинки) отдаёт без изменений
